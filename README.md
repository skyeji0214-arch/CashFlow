# 💰 나의 가계부

구글 시트 가계부를 휴대폰 앱처럼 쓰기 위한 깃허브 페이지예요.
실제 화면과 데이터는 구글 앱스크립트 웹앱에서 불러오고, 이 저장소에는 **여는 화면과 아이콘만** 있어요.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 앱스크립트 웹앱을 화면 가득 띄워요 (주소는 이 파일 안의 `APP_URL`) |
| `manifest.json` | 홈 화면 앱 이름·아이콘·색 설정 |
| `sw.js` | 홈 화면 설치용 서비스워커 (가계부 데이터는 저장 안 함) |
| `icons/` | 지갑 아이콘 (192·512·애플·파비콘) |

## 웹앱 주소가 바뀌었을 때
`index.html`을 열고 연필(✏️) 버튼 → `var APP_URL = '...'` 안의 주소만 바꾸고 **Commit changes**.
(앱스크립트에서 "배포 관리 → 편집 → 새 버전"으로 업데이트하면 주소가 그대로라 고칠 필요 없어요.)
